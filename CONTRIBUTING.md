# Contributing to PRCoach

Thanks for your interest in contributing to PRCoach! Contributions help make this project better and more useful for everyone.

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes.
4. Commit with a clear message.
5. Open a pull request against `main`.

## Reporting Issues

- Use issues to report bugs, request enhancements, or suggest new ideas.
- Provide steps to reproduce problems when possible.
- Include relevant environment details, such as Python version and database configuration.

## Code Guidelines

- Keep changes small and focused.
- Follow Python conventions and formatting.
- Use type hints where appropriate.
- Document new functionality in the README or code comments.

## Development Notes

- The application is built with FastAPI and SQLAlchemy.
- Environment variables are loaded from `.env`.
- Please keep any sensitive data out of commits.
